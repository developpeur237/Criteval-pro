Laragon deployment steps (Windows)

Preconditions:
- Laragon installed (default path: `C:\laragon`) with Apache & MySQL running.
- You have administrative rights to edit hosts file if creating a vhost.

1) Copy project into Laragon www folder

Option A (recommended - keep workspace copy): use `robocopy` to mirror files into Laragon www:

```powershell
robocopy "e:\DEV\Criteva_pro" "C:\laragon\www\Criteva_pro" /MIR /COPYALL /R:2 /W:2
```

Option B (quick): drag & drop the `Criteva_pro` folder into `C:\laragon\www` using Explorer.

2) Create the database and import schema

Open Laragon terminal (or PowerShell) and run:

```powershell
cd C:\laragon\bin\mysql\mysql-*-*\bin  # optional: use mysql binary path
mysql -u root -e "CREATE DATABASE IF NOT EXISTS criteval_pro CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
mysql -u root criteval_pro < "e:\DEV\Criteva_pro\database\criteval_pro.sql"
```

Note: Laragon's MySQL root user usually has no password by default. If you changed it, add `-p` and provide the password.

3) Update `config/config.php` for production/local Laragon

- Set `BASE_URL` for local access. Two options:
  - Access via folder: `http://localhost/Criteva_pro/` → set `BASE_URL` to that.
  - Preferred: create a friendly vhost `criteva_pro.test` and set `BASE_URL` to `http://criteva_pro.test/`.
- Update DB constants if needed:
  - `DB_HOST` = `127.0.0.1`
  - `DB_NAME` = `criteval_pro`
  - `DB_USER` = `root`
  - `DB_PASS` = `` (empty) or your MySQL password

4) (Optional) Create virtual host in Laragon

- In Laragon: Menu → Apache → Sites → Add
  - Name: `criteva_pro.test`
  - Path: `C:\laragon\www\Criteva_pro`
  - Laragon will update the hosts file and restart Apache.

If you prefer manual hosts update:

```powershell
notepad C:\Windows\System32\drivers\etc\hosts
# add line:
127.0.0.1 criteva_pro.test
```

And add a VirtualHost in Apache config (rarely needed—Laragon automates this): edit `C:\laragon\etc\apache2\vhosts.conf` and add a `<VirtualHost>` block.

5) Start Laragon services

- Open Laragon and click "Start All". Verify Apache and MySQL are running.

6) Access the site

- Using folder access: `http://localhost/Criteva_pro/`
- Using vhost: `http://criteva_pro.test/`

7) Verify and debug

- Check `logs` (Apache/PHP) in Laragon if 500 errors occur.
- Ensure `.htaccess` is allowed (AllowOverride All) — Laragon default allows .htaccess.
- If mod_rewrite not enabled, enable it via Laragon Apache modules UI.

8) Post-deploy tasks

- Re-run the quick-tests checklist from `steps.txt` (login, projects, criteria, evaluation levels).
- If using SMTP (PHPMailer), update SMTP settings in `config/config.php` for local testing (e.g., Mailtrap or Mailhog).
- Optionally enable HTTPS via Laragon's SSL tool (Menu → Apache → SSL)

Troubleshooting tips:
- 404 on assets: confirm `BASE_URL` ends with trailing slash and asset paths use `BASE_URL` constant.
- Database connection errors: verify `DB_HOST`, `DB_USER`, `DB_PASS`, and that MySQL service is running.
- Permission issues: On Windows, file permissions are rarely a blocker; ensure files are not blocked by Windows Defender/AV.
