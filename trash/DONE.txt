## 📝 Code Examples

### How Navigation Works
```html
<!-- In index.html -->
<a href="login.html">Se connecter</a>
<a href="candidate.html">Espace Candidat</a>

<!-- In login.html -->
<button onclick="window.location.href='dashboard.html'">Login</button>

<!-- In dashboard.html -->
<button onclick="window.location.href='index.html'">Return</button>
```

### How Partials Load
```javascript
// In assets/js/app.js
includePartial('#sidebarPlaceholder', 'views/partials/sidebar.html');
includePartial('#topbarPlaceholder', 'views/partials/topbar.html');
includePartial('#modalsPlaceholder', 'views/partials/modals.html');
```

### How CSS Variables Work
```css
/* In assets/css/styles.css */
:root {
  --primary: #1A3C5E;
  --secondary: #2EAF7D;
  --accent: #F5A623;
}

/* Used everywhere */
.btn-primary { background: var(--primary); }
.badge-success { color: var(--secondary); }
```

## 🎓 For Next Steps

### If You Want to...
- **Modify colors** → Edit CSS variables in `assets/css/styles.css`
- **Add new page** → Create new HTML file, import CSS/JS, use partials
- **Change dashboard modules** → Edit `dashboard.html` module divs
- **Update form fields** → Edit form sections in `candidate.html`
- **Deploy to web** → Upload entire folder to hosting server

### Development Tips
- All CSS in one file (easy to find & modify)
- All JS in one file (easy to add new functions)
- Partials in separate files (easy to reuse)
- Use browser DevTools (F12) to debug and inspect
